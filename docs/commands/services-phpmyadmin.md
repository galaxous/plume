# Native phpMyAdmin

## Purpose

phpMyAdmin in macOS/Linux native mode: `brew install phpmyadmin` (or apt), `PMA_*` env → `config.inc.php`, `php -S 127.0.0.1:8081`.

## Usage

```bash
# ~/.config/plume/.env
PLUME_PHPMYADMIN_ENABLED=true
PLUME_PHPMYADMIN_PORT=8081
PMA_ARBITRARY=1
PMA_AUTH_TYPE=cookie

plumectl services install phpmyadmin --mode=native
plumectl services up phpmyadmin --mode=native
# Login form: Server + user + password (like Laradock)
# native: dropdown label mariadb|mysql; TCP host always 127.0.0.1 (port PLUME_*_PORT)
# docker-lite: Server = mariadb or mysql (container hostname)
```

A separate phpMyAdmin server record is generated for each active engine (`verbose=mariadb|mysql`, `host=127.0.0.1`, port=`PLUME_MARIADB_PORT` / `PLUME_MYSQL_PORT`). The dropdown shows only **running** (or enabled) engines.

**macOS Homebrew:** `mariadb` and `mysql` formulas conflict (same binary); you cannot run both via native brew at once. If you need both like Laradock: one native, the other `docker-lite`, or only `mariadb` native.

Writing `127.0.0.1 mariadb mysql` into `/etc/hosts` is optional (`PLUME_NATIVE_DB_HOSTS_SYNC`); phpMyAdmin config no longer depends on hostname (D-142).

## Parameters

| Variable | Description | Default |
|----------|-------------|---------|
| `PLUME_PHPMYADMIN_PORT` / `PMA_PORT` | HTTP port | `8081` |
| `PMA_ARBITRARY` | Extra free Server field + Laradock parity | `1` |
| `PMA_AUTH_TYPE` | `cookie` (login form) or `config` (auto login) | `cookie` |
| `PLUME_MARIADB_PORT` / `PLUME_MYSQL_PORT` | Per-engine TCP port (must differ when both used) | `3306` / `3307` |
| `PLUME_NATIVE_DB_HOSTS_SYNC` | `mariadb`/`mysql` hostname → `127.0.0.1` | `true` |
| `PMA_DB_ENGINE` | **docker-lite:** compose `depends_on`; **native arbitrary:** optional | `mariadb` |
| `PMA_HOST` / `PMA_DB_PORT` | Fixed target only when `PMA_ARBITRARY=0` | — |
| `PMA_USER` / `PMA_PASSWORD` | `services credentials` hint | MariaDB root |

- `state/native/phpmyadmin/htdocs/` — phpMyAdmin files (copy from brew/apt)
- `state/native/phpmyadmin/htdocs/config.inc.php` — generated by Plume

## Output / exit-code

- `services url phpmyadmin`: `url=http://127.0.0.1:8081`
- `services credentials phpmyadmin`: db host/port/user/password + http_port
- `0`: success
- `2`: phpmyadmin not installed, php missing, or DB engine disabled

## Examples

```bash
open http://127.0.0.1:8081
plumectl services credentials phpmyadmin --mode=native
```

## Error scenarios

- **8081 connection refused**: `services up phpmyadmin` not run, or `brew install phpmyadmin` missing.
- **DB login failed**: `PMA_PASSWORD` vs `PLUME_MARIADB_ROOT_PASSWORD` mismatch; align `.env` + `services restart mariadb`.
- **getaddrinfo for mariadb failed**: old config used hostname; `services restart phpmyadmin` (D-142: host=127.0.0.1). At login pick `mariadb` from Server dropdown; password = `MARIADB_ROOT_PASSWORD`.
- **services.yml disabled**: `.env` (`PLUME_PHPMYADMIN_ENABLED=true`) wins over the manifest.
