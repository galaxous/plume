## Native Mode

### Calisan

- Laradock-benzeri service alias contract (phase 11)
- PHP matrix, shim, extension sync, `services up php` autoprovision
- Site + php upstream + strict nginx/apache/caddy publish
- `env init`, native preset templates

### Eksik / opt-in

- Non-PHP servislerde gercek OS service manager entegrasyonu: `PLUME_NATIVE_HOST_PROVISION=true` (faz 12)
- `dnf` PHP surum kurulumu kismen manuel
- Native `workspace` shell deneyimi laradock kadar olgun degil
