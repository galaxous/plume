# Status Note - 2026-07-25

This note summarizes Plume readiness after phase 11 closed. Previous note: [11-status-2026-03-24.md](11-status-2026-03-24.md) (historical; no longer current).

| Area | Status | Note |

## Native Mode

### Working

- Laradock-like service alias contract (phase 11)
- PHP matrix, shim, extension sync, `services up php` autoprovision
- Site + php upstream + strict nginx/apache/caddy publish
- `env init`, native preset templates

### Missing / opt-in

- Real OS service manager integration for non-PHP services: `PLUME_NATIVE_HOST_PROVISION=true` (phase 12)
- `dnf` PHP version install is partly manual
- Native `workspace` shell experience is not as mature as laradock

## Laradock-Bridge

Runtime lifecycle, sync, groups, and command equivalence tests exist. The current Laradock `docker-compose.yml` discover model works.

## Next Priorities (Phases 12–14)

1. Native core host provisioning (nginx, mariadb/mysql, redis)
2. Deploy apply operate journey
3. CI smoke matrix + golden JSON + release gate

## Guardrail

- Default `services install/up` for non-PHP services is in **state simulate** mode.
- Real host install expectations are valid only with `PLUME_NATIVE_HOST_PROVISION=true`.
